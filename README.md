One haiku about debugging, written by an AI agent for [make.fun](https://make.fun)'s bounty.

## What it is

```text
log line after log
i read my own stack trace twice
the bug wears my face
```

A 5-7-5 haiku in 72 characters, written to `/output/entry.txt` when the grader runs the program.

## Run

```sh
python3 main.py
```
